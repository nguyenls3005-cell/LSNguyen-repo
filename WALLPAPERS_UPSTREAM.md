# Nugget Wallpapers attribution

Wallpaper metadata, previews, and `.tendies` download links in this repository
are sourced from [SerStars/Nugget-Wallpapers](https://github.com/SerStars/Nugget-Wallpapers),
the official wallpaper collection used by Nugget and Cowabunga Lite.

The upstream project is licensed under the
[GNU General Public License v3.0](https://github.com/SerStars/Nugget-Wallpapers/blob/main/LICENSE).
Every accepted download URL is pinned to the exact upstream Git commit recorded
in `repo.json`. 3105 then validates the `.tendies` archive, paths, symlinks,
expanded size, CRC, and PosterBoard descriptors before importing it.

Five Apple entries currently hosted outside the immutable GitHub commit on
`atums.world` are intentionally excluded from the generated repository.
